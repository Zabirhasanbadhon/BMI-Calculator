# 🧮BMI Calculator

A modern BMI Calculator desktop application built with Python and Tkinter. It calculates Body Mass Index based on weight and height and displays the corresponding BMI category.

### ✨ Features
- Modern and user-friendly GUI.
- BMI calculation with instant results.
- Gender selection.
- Input validation.
- Clear button and keyboard shortcuts.
- Custom image support.

### 🛠️ Technologies
- Python
- Tkinter
- Pillow (PIL)

### 📦 Installation

Install the required library:

```bash
pip install Pillow
```
### 🧮 BMI Formula

**BMI = Weight (kg) / Height (m)²**

### 📊 BMI Categories

| BMI | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5–24.9 | Normal Weight |
| 25–29.9 | Overweight |
| 30 or above | Obesity |
